# Data layout

## `raw/`

Unmodified responses from source systems. Store each collection run in a dated
subdirectory and retain response metadata where available. Raw files should not
be hand-edited.

Suggested naming convention:

```text
data/raw/course_schedule/2026-10-22/sections_2026w1_page_0001.json
```

## `processed/`

Deterministic outputs derived from raw data. These files may be regenerated by
the scripts in `collection/` and should never be manually corrected. Corrections
belong in parsing or normalization code.

Later stages can add separate datasets for Calendar courses, prerequisites,
program requirements, and offering history without changing the raw sources.

The initial raw-source layout separates scheduled offerings from the two
Calendar datasets:

```text
data/raw/course_schedule/
data/raw/academic_calendar/course_descriptions/
data/raw/academic_calendar/program_requirements/
```
